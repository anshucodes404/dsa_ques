In this question what is happening is that we need to find max product, so there would be two scenarios

(1) even neg numbers : no issue
(2) odd neg numbers : the max product would be excluding any one neg number i.e. either left or right side of that number, so we are calculating product from both sides


class Solution {
    public int maxProduct(int[] nums) {
        int max = Integer.MIN_VALUE;
       

        int prod = 1;
        for(int i = 0; i < nums.length; i++){
            prod *= nums[i];
            
            max = Math.max(prod, max);
            if(prod == 0) prod = 1;
        }

        prod = 1;
        for(int i = nums.length - 1; i >= 0 ; i--){
            prod *= nums[i];
            
            max = Math.max(prod, max);
            if(prod == 0) prod = 1;
        }

        return max;
    }
}
